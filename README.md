# HIKR Data Processing

Turbo/Bun monorepo for processing HIKR exports.

## Workspaces

- `agent`: Mastra agents.
- `apps/data-pipeline`: Stateless preprocessing logic.
- `packages/db`: Prisma schema files for the enriched database.

## Commands

```sh
bun install
bun run typecheck
bun run test
bun run build
```
