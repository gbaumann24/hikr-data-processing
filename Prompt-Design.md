# Prompt Design

Goal: Extract structured attributes for alpine climbing tours from Hikr tour reports. The output must be machine-readable.

## Global Rules

- Each leaf attribute is output directly as a value.
- If a value is not explicitly mentioned, the value is `null`.
- For array fields, the empty value is `[]` instead of `null`.
- Do not guess. Only obvious normalizations are allowed, e.g. `1 h 30` to `90` minutes.
- If statements conflict, prefer the more specific or more recent passage. If the conflict cannot be resolved, output `null`.
- Numbers are stored without units; the unit is part of the field name, e.g. `laenge_m`, `dauer_min`.
- Yes/no fields use `true`, `false`, or `null`.
- Enum values are lowercase.
- Arrays contain deduplicated values.
- The Abstieg (descent) begins upon reaching the summit or the Ausstieg of the route.
- The route is the climbing path from the Einstieg to the Ausstieg. The Zustieg (approach to the Einstieg) and the Abstieg (descent) are not part of the route.

## Output Format

The tables below describe the expected leaf attributes and their direct JSON values.

```json
{
  "ausruestung": {},
  "zeitbedarf": {},
  "absicherung": {},
  "schuhwerk": {},
  "gelaende_und_gefahren": {},
  "klettern": {},
  "anreise": {},
  "zustieg_und_abstieg": {},
  "besonderes": {}
}
```

## Ausruestung (Equipment)

| Field                                           | Type / Values                                                              | Description                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ausruestung.seil.art`                          | `"halbseil", "zwillingsseil", "einfachseil", null`                         | Type of rope carried. `einfachseil`: single strand, often written as "50er Seil" or simply "Seil" without qualifier — in that case `null`, unless the type is clearly named. `halbseil`: two strands (8–9 mm), strands may be clipped individually; signal words: "Halbseile", "Doppelseil 2x50m". `zwillingsseil`: thin double rope (~7.5–8 mm), only used as a double strand; signal word: "Zwillingsseile". |
| `ausruestung.seil.laenge_m`                     | `number, null`                                                             | Length of the rope carried, in meters. Recognizable from phrases like "50m-Seil", "2x60m" (then `60`), "Seil 40 Meter". Capture the length per strand only, not the sum.                                                                                                                                                                                                                                       |
| `ausruestung.mobile_absicherung.erforderlich`   | `true, false, null`                                                        | Whether mobile protection (Friends/Cams, Keile/Nuts, slings) is strictly required because the route is not, or only partially, equipped with fixed Haken. Signal words: "muss selber abgesichert werden", "clean", "keine Haken", "Keile zwingend". Only `false` if the report explicitly states that no mobile gear is needed (e.g. "komplett eingebohrt, Exen reichen").                                     |
| `ausruestung.mobile_absicherung.empfohlen`      | `true, false, null`                                                        | Whether mobile protection is recommended as a useful supplement even though the route is fundamentally equipped (e.g. bolted). Signal words: "ein paar Friends schaden nicht", "Camalots zur Ergaenzung empfohlen", "wer mag, nimmt Keile mit".                                                                                                                                                                |
| `ausruestung.mobile_absicherung.verwendet`      | `true, false, null`                                                        | Whether the authors actually placed mobile protection during the climb (placed Friends/Keile, slung Schlingen over spikes, or threaded Sanduhren). Signal words: "legten wir einen Friend", "Sanduhr gefaedelt", "Koepflschlinge gelegt".                                                                                                                                                                      |
| `ausruestung.mobile_absicherung.moeglichkeiten` | `string, null`                                                             | Free text: how well, how often, and where mobile protection can be placed. Examples from reports: "gute Rissstrukturen fuer Friends", "kaum Placements", "Sanduhren vorhanden". Briefly preserve the original wording.                                                                                                                                                                                         |
| `ausruestung.mobile_absicherung.friends`        | `array<{ groesse: string/null, anzahl: number/null }>`                     | Friends/Cams carried or recommended (camming devices with movable segments). Size specifications such as "0.3–2", "Camalot 0.5" go into `groesse` as a string. "Ein Satz Friends" (a full set) → one entry with `groesse: "satz"`, `anzahl: null`.                                                                                                                                                             |
| `ausruestung.mobile_absicherung.keile`          | `array<{ groesse: string/null, anzahl: number/null }>`                     | Klemmkeile carried or recommended. Synonyms in reports: Keile, Nuts, Rocks, Stopper, Hexentrics. Same logic as for Friends ("Satz Keile" → `groesse: "satz"`).                                                                                                                                                                                                                                                 |
| `ausruestung.schlingen`                         | `array<{ typ: string/null, laenge_cm: number/null, anzahl: number/null }>` | Slings carried. `typ` e.g. "bandschlinge", "zackenschlinge" (also called Koepflschlinge), "sanduhrschlinge", "reepschnur", "kevlarschlinge". Length specifications like "120er Schlinge" → `laenge_cm: 120`.                                                                                                                                                                                                   |
| `ausruestung.expresskarabiner.anzahl`           | `number, null`                                                             | Number of quickdraws carried or recommended. Synonyms: Expressen, Exen, Expressschlingen, Runner. "10 Exen" → `10`. Do not convert vague statements ("einige Exen") into a number → `null`.                                                                                                                                                                                                                    |
| `ausruestung.zusaetzlich`                       | `string[]`                                                                 | Other explicitly mentioned equipment that fits no other field: e.g. helmet, Pickel (ice axe), Steigeisen (crampons), headlamp, Abseilgeraet (rappel device), Prusikschlinge, bivy sack. Do not capture clothing or food.                                                                                                                                                                                       |

## Zeitbedarf (Time Required)

Always normalize time specifications to minutes ("1 h 30" → `90`, "dreiviertel Stunde" → `45`). For ranges ("2–3 h"), take the mean if the authors' own time is not stated; otherwise prefer the time actually taken.

| Field                              | Type / Values  | Description                                                                                                                                                                                                                                  |
| ---------------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `zeitbedarf.zustieg_min`           | `number, null` | Duration of the Zustieg from the starting point (parking lot, transit stop, Huette) to the Einstieg of the route, in minutes. Signal words: "Zustieg", "bis zum Einstieg", "Wandfuss erreicht nach".                                         |
| `zeitbedarf.reine_kletterzeit_min` | `number, null` | Pure climbing time from the Einstieg to the Ausstieg, in minutes, excluding Zustieg and Abstieg. Signal words: "Kletterzeit", "fuer die Route brauchten wir", "in der Wand". Breaks at the Stand count toward this unless listed separately. |
| `zeitbedarf.abstieg_min`           | `number, null` | Duration of the Abstieg in minutes, measured from the summit or Ausstieg back to the starting point. Rappelling time counts toward the Abstieg if rappelling is the descent route.                                                           |

## Absicherung (Protection)

| Field                                     | Type / Values                                   | Description                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `absicherung.hakenabstaende.bewertung`    | `"sehr_gut", "gut", "mittel", "schlecht", null` | Assessment of the spacing between fixed intermediate protection points (Haken). Only fill in if Haken are present or mentioned. Mapping: "plaisirmaessig eng", "Haken wo man sie braucht" → `sehr_gut`/`gut`; "teils weite Abstaende", "alpin abgesichert" → `mittel`; "Runouts", "sehr weit", "boese Abstaende" → `schlecht`. |
| `absicherung.hakenabstaende.beschreibung` | `string, null`                                  | Free-text justification regarding the Hakenabstaende: where the spacing is tight or wide, in which Seillaengen runouts occur, whether the hard sections are well protected.                                                                                                                                                    |
| `absicherung.staende.gebohrt`             | `true, false, null`                             | Whether the Standplaetze (belay anchors between Seillaengen) are bolted or fixed in place. Signal words: "Bohrhakenstaende", "Staende eingerichtet", "Stand mit zwei Bolts". `false` for "Staende selber bauen", "Staende an Koepfln/Sanduhren".                                                                               |
| `absicherung.staende.beschreibung`        | `string, null`                                  | Details about the Standplaetze: material (Bolts, Normalhaken, chains, rappel rings), condition, reliability, whether linked, whether suitable for rappelling.                                                                                                                                                                  |
| `absicherung.hakenzustand.bewertung`      | `"gut", "mittel", "schlecht", null`             | Condition of the existing fixed Haken. "neu saniert", "solide Klebehaken" → `gut`; "teils aeltere Haken" → `mittel`; "rostig", "fragwuerdig", "Schlaghaken von anno dazumal" → `schlecht`.                                                                                                                                     |
| `absicherung.hakenzustand.beschreibung`   | `string, null`                                  | Free text about the Haken: type (Bohrhaken/Bolts, Klebehaken, Normalhaken/Schlaghaken), age, rust, whether the route has been saniert (re-equipped).                                                                                                                                                                           |

## Schuhwerk (Footwear)

Footwear types: `bergschuhe` (stiff boots for alpine terrain), `zustiegsschuhe` (light approach shoes with climbing-oriented soles), `turnschuhe` (regular sneakers), `kletterschuhe` (tight shoes with friction soles, used only for climbing).

| Field                    | Type / Values                                           | Description                                                                                                                                                                      |
| ------------------------ | ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schuhwerk.zustieg.typ`  | `"bergschuhe", "zustiegsschuhe", "turnschuhe", null`    | Which footwear is mentioned or recommended for the Zustieg to the Einstieg. Only fill in if the report explicitly addresses the Zustieg ("Turnschuhe reichen fuer den Zustieg"). |
| `schuhwerk.klettern.typ` | `"kletterschuhe", "bergschuhe", "zustiegsschuhe", null` | Which footwear is worn or recommended on the climbing route itself. `bergschuhe`/`zustiegsschuhe` occur when the route is easy enough ("alles in Bergschuhen kletterbar").       |
| `schuhwerk.abstieg.typ`  | `"bergschuhe", "zustiegsschuhe", "turnschuhe", null`    | Which footwear is mentioned for the Abstieg. Common signal: "Schuhe fuer den Abstieg mitnehmen" or stashing shoes at the Einstieg.                                               |

## Gelaende und Gefahren (Terrain and Hazards)

| Field                                               | Type / Values                                                                                                                         | Description                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gelaende_und_gefahren.charakter.exposition`        | `string, null`                                                                                                                        | Compass direction the wall or route faces, as an abbreviation: `N`, `NO`, `O`, `SO`, `S`, `SW`, `W`, `NW`. Signal words: "Suedwand", "nach Suedosten ausgerichtet". Caution: do not confuse with "ausgesetzt/Ausgesetztheit" — that describes airy, exposed climbing, not the compass direction.                                                                                        |
| `gelaende_und_gefahren.charakter.sonnig`            | `true, false, null`                                                                                                                   | Whether a sunny position is explicitly mentioned ("Sonne ab Mittag", "brutheisse Suedwand" → `true`; "schattig", "kommt kaum Sonne hin" → `false`). Do not infer from the Exposition.                                                                                                                                                                                                   |
| `gelaende_und_gefahren.charakter.schnell_trocknend` | `true, false, null`                                                                                                                   | Whether the rock dries quickly after rain or wetness. Signal words: "trocknet schnell", "schon am Vormittag nach Regen kletterbar"; opposite: "bleibt lange nass", "sickert" → `false`.                                                                                                                                                                                                 |
| `gelaende_und_gefahren.charakter.felsart`           | `"granit", "gneis", "kalk", "dolomit", "sandstein", "quarzit", "schiefer", "konglomerat", "nagelfluh", "serpentinit", "basalt", null` | Rock type of the route, if mentioned. Map cues like "rauer Granit", "loechriger Kalk", "Nagelfluh" directly. Do not guess from the region.                                                                                                                                                                                                                                              |
| `gelaende_und_gefahren.gefahren`                    | `array<{ typ: string, beschreibung: string/null }>`                                                                                   | All hazards mentioned on the Zustieg, route, or Abstieg. Typical `typ` values: "bruechiger_fels" (loose blocks, "Vorsicht mit dem Seil"), "steinschlag" (rockfall, also caused by other parties), "gras" (grassy sections), "naesse", "verhauer" (risk of going off-route), "absturzgelaende", "wechten" (cornices), "spalten" (crevasses). `beschreibung` states location and context. |

## Klettern (Climbing)

| Field                                          | Type / Values                                                                                                                                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `klettern.schluesselstellen.vorhanden`         | `true, false, null`                                                                                                                           | Whether at least one Schluesselstelle is mentioned. The Schluesselstelle (also "Crux") is the most difficult spot or passage of the route; the "Schluessellaenge" is the most difficult Seillaenge. Both count.                                                                                                                                                                                                                                                                                                                                                                              |
| `klettern.schluesselstellen.stellen`           | `array<{ wo: string/null, beschreibung: string/null }>`                                                                                       | Position (`wo`, e.g. "3. Seillaenge", "kurz vor dem Ausstieg") and description of each Schluesselstelle (style of climbing, grade, how it feels).                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `klettern.schwierigkeit.verhaeltnis`           | `"leichter", "wie_bewertet", "schwerer", null`                                                                                                | The authors' subjective impression compared to the official grade (e.g. UIAA or French grade from the guidebook/Topo). "gut machbar fuer den Grad", "weich bewertet" → `leichter`; "Bewertung passt" → `wie_bewertet`; "hart fuer 5c", "anspruchsvoller als angegeben" → `schwerer`.                                                                                                                                                                                                                                                                                                         |
| `klettern.schwierigkeit.beschreibung`          | `string, null`                                                                                                                                | Justification of the difficulty impression: why it felt harder or easier (e.g. abgespeckt — polished rock, boldness required, pumpy, technical).                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `klettern.abseilen.moeglich`                   | `true, false, null`                                                                                                                           | Whether Abseilen (rappelling on a rope threaded through a fixed anchor) is mentioned as a descent or retreat option. Signal words: "abseilen ueber die Route", "Abseilstellen eingerichtet".                                                                                                                                                                                                                                                                                                                                                                                                 |
| `klettern.abseilen.anzahl`                     | `number, null`                                                                                                                                | Number of required or described rappels (maneuvers from Stand to Stand). "4x abseilen", "in 5 Abseilern" → the corresponding number.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `klettern.abseilen.laengen_m`                  | `number[]`                                                                                                                                    | Individual rappel lengths in meters, if mentioned ("abseilen 25m, dann 50m" → `[25, 50]`). Important for determining whether an Einfachseil suffices.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `klettern.abseilen.zum_einstieg`               | `true, false, null`                                                                                                                           | Whether rappelling leads directly back to the Einstieg (convenient for stashed gear). Signal words: "abseilen zum Einstieg", "ueber die Route zurueck zum Wandfuss".                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `klettern.abseilen.abseilpiste`                | `true, false, null`                                                                                                                           | Whether an Abseilpiste exists: a dedicated rappel line equipped with fixed anchors, often separate from the route. Signal words: "Abseilpiste", "eingerichtete Abseilstrecke".                                                                                                                                                                                                                                                                                                                                                                                                               |
| `klettern.charakter.kletterstil`               | `array<"platte", "riss", "grat", "kante", "wand", "verschneidung", "ueberhang", "dach", "pfeiler", "kamin">`                                  | Predominant terrain forms of the climbing. `platte`: inclined, low-feature slab (also friction climbing); `riss`: narrow crack (jamming, Piazen/laybacking); `grat`: ridge dropping off on both sides; `kante`: steep, ridge-like outer edge (arête); `wand`: steep face climbing; `verschneidung`: inside corner formed by two walls (dihedral); `ueberhang`: leaning beyond vertical; `dach`: horizontal overhang (roof); `pfeiler`: tower-like protruding structure (pillar); `kamin`: wide crack the whole body fits into (chimney; Stemm-/Spreiztechnik). | `klettern.routenverlauf.routenfindung`         | `"einfach", "mittel", "schwierig", null`                                                                                                      | How difficult it is to identify the line of the route. "logische Linie", "Haken immer sichtbar" → `einfach`; "etwas Spuersinn noetig" → `mittel`; "Verhauer-Gefahr", "Topo zwingend", "lange gesucht" → `schwierig`.                                                                                                                                                                                                                                                                                                                                                                         |
| `klettern.routenverlauf.beschreibung`          | `string, null`                                                                                                                                | Free text about the line and orientation: prominent features, where Verhauer (unintentionally going off-route) is a risk, what to orient by.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `klettern.routenverlauf.rueckzug_moeglich`     | `true, false, null`                                                                                                                           | Whether Rueckzug (bailing on the tour) or escape options from the route are mentioned, e.g. rappelling from every Stand, traversing into easier terrain, exiting onto a Band (ledge).                                                                                                                                                                                                                                                                                                                                                                                                        |
| `klettern.routenverlauf.rueckzug_beschreibung` | `string, null`                                                                                                                                | Where and how a Rueckzug is possible (e.g. "bis zur 4. SL von jedem Stand abseilbar", "ab dem Band Ausstieg nach links").                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `klettern.seillaengen_verbinden.moeglich`      | `true, false, null`                                                                                                                           | Whether Seillaengen (pitches between two Standplaetze) can be linked to skip belays. Signal words: "SL 3 und 4 verbinden", "mit 60m-Seil zusammenhaengbar".                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `klettern.seillaengen_verbinden.beschreibung`  | `string, null`                                                                                                                                | Which Seillaengen can be linked and under what conditions (rope length in meters, rope drag, gear requirements).                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `klettern.seillaengen`                         | `array<{ nummer: number/null, schwierigkeit: string/null, anzahl_bohrhaken: number/null, laenge_m: number/null, beschreibung: string/null }>` | Structured description of individual Seillaengen, if the report covers them one by one. `nummer`: position in the route (1 = first SL); `schwierigkeit`: grade as a string, as given in the report (e.g. "5c", "VI-", "4a"); `anzahl_bohrhaken`: number of fixed Bohrhaken in that pitch; `laenge_m`: length in meters; `beschreibung`: character, key spots, remarks.                                                                                                                                                                                                                       |

## Anreise (Getting There)

| Field                               | Type / Values       | Description                                                                                                                                                                           |
| ----------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `anreise.parkplatz.ort`             | `string, null`      | Name or location description of the parking lot or parking option (e.g. "Parkplatz Saentisbahn", "Kehrplatz am Strassenende", "Weiler Hinterberg").                                   |
| `anreise.parkplatz.kosten`          | `string, null`      | Costs or fee information as free text ("5 CHF/Tag", "Parkuhr", "gratis"). Also capture mere mentions that fees apply.                                                                 |
| `anreise.parkplatz.besonderheiten`  | `string, null`      | Practical parking notes: few spots, fills up early, tight, driving ban beyond a certain point, key pickup required, private road.                                                     |
| `anreise.oev.verkehrsmittel`        | `string[]`          | All mentioned public transport modes for getting there: e.g. "zug", "bus", "postauto", "rufbus", "luftseilbahn", "schiff". Collect in lowercase.                                      |
| `anreise.oev.endstation`            | `string, null`      | Name of the stop or station where one gets off for the start of the tour (e.g. "Wasserauen", "Steingletscher, Hotel").                                                                |
| `anreise.oev.luftseilbahn_moeglich` | `true, false, null` | Whether a Luftseilbahn (cable car, also Gondel, Seilbahn) can be used for the approach or descent. Also capture if the authors merely mention it without using it.                    |
| `anreise.oev.anmeldung_noetig`      | `true, false, null` | Whether registration or a reservation is required for a transport mode (typical for Rufbusse and small cable cars). Signal words: "telefonisch anmelden", "Reservation erforderlich". |

## Zustieg und Abstieg (Approach and Descent)

The Zustieg is the way from the starting point to the Einstieg (start of the route). The Abstieg begins at the summit or Ausstieg (end of the route) and leads back to the starting point.

| Field                                                  | Type / Values                         | Description                                                                                                                                                                                                        |
| ------------------------------------------------------ | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `zustieg_und_abstieg.zustieg.einstiegsfindung`         | `"einfach", "mittel", "schwer", null` | How easy it is to find the Einstieg of the route. "nicht zu verfehlen", "beschriftet", "Steinmann markiert" → `einfach`; "etwas suchen" → `mittel`; "lange gesucht", "ohne GPS kaum zu finden" → `schwer`.         |
| `zustieg_und_abstieg.zustieg.beschreibung`             | `string, null`                        | Where the Einstieg is located and how to recognize it: directions, markings (Steinmaenner/cairns, route name on the rock, first Bohrhaken visible), prominent features.                                            |
| `zustieg_und_abstieg.zustieg.schwierigkeit`            | `string, null`                        | Technical or alpine difficulty of the Zustieg as free text: hiking scale (e.g. "T3"), scrambling sections, snowfields, scree, fixed cables, exposed passages.                                                      |
| `zustieg_und_abstieg.abstieg.fuehrt_zum_einstieg`      | `true, false, null`                   | Whether the Abstieg passes the Einstieg again. Relevant for gear stashed at the Einstieg ("Schuhdepot"). Signal words: "zurueck zum Einstieg", "Rucksackdepot wird wieder passiert".                               |
| `zustieg_und_abstieg.abstieg.verpflegung_moeglich`     | `true, false, null`                   | Whether the Abstieg passes a place offering food or drink: Huette (SAC-Huette, Berggasthaus), restaurant, Alpwirtschaft, kiosk.                                                                                    |
| `zustieg_und_abstieg.abstieg.verpflegung_beschreibung` | `string, null`                        | Name or location of the food option (e.g. "Berggasthaus Aescher", "Doldenhornhuette").                                                                                                                             |
| `zustieg_und_abstieg.abstieg.schwierigkeit`            | `string, null`                        | Difficulty and concrete challenges of the Abstieg as free text: hiking scale, downclimbing sections, scree, old snowfields, orientation, rappel sections (unless captured structurally under `klettern.abseilen`). |

## Besonderes (Miscellaneous)

| Field                      | Type / Values  | Description                                                                                                                                                                                                          |
| -------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `besonderes.saisonalitaet` | `string, null` | Notes on particularly suitable or unsuitable seasons and conditions: e.g. "Fruehling wegen Naesse meiden", "ideal im Herbst", "im Hochsommer zu heiss", "Altschnee bis Juni im Zustieg", "nach Regen 2 Tage warten". |
| `besonderes.hinweise`      | `string[]`     | Other relevant notes that fit no other category: e.g. crag closures (bird protection), gear stashes, mobile reception, water sources, Huette reservations, Topo sources, warnings to other parties.                  |

## Example

```json
{
  "zeitbedarf": {
    "zustieg_min": 45
  },
  "klettern": {
    "abseilen": {
      "moeglich": true
    }
  }
}
```
